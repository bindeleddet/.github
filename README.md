# Bindeleddet NTNU

Bindeleddet NTNU er et kontaktorgan mellom næringslivet og sivilingeniørstudentene ved Industriell økonomi og teknologiledelse og andre sivilingeniørstudier.

Bindeleddets digitale tjenester utvikles og vedlikeholdes av BL-IT.
